✏️ תרגיל פתיחה

כתבו את התוכנית הבאה ב-C# :
  • נתונה כיתה בבית ספר. קלטו מהמשתמש את מספר המקצועות הנלמדים בכיתה
  • נניח שיש 3 תלמידים בכיתה
  • עבור כל תלמיד, צרו ציונים אקראיים (בטווח: 0-100) על פי מספר המקצועות
  • א. הדפיסו את הממוצע לכל תלמיד
  • ב. הדפיסו את הממוצע לכל מקצוע

💬 כיצד פתרתם?

פתרון טבעי — מערך לכל תלמיד:

int numSubjects = int.Parse(Console.ReadLine()); Random rand = new Random(); int[] student0 = new int[numSubjects]; int[] student1 = new int[numSubjects]; int[] student2 = new int[numSubjects]; for (int i = 0; i < numSubjects; i++) { student0[i] = rand.Next(0, 101); student1[i] = rand.Next(0, 101); student2[i] = rand.Next(0, 101); } for (int i = 0; i < numSubjects; i++) { double avg = (student0[i] + student1[i] + student2[i]) / 3.0; Console.WriteLine("Subject " + i + ": average = " + avg); }
מה אם היו לנו 30 תלמידים? 100 תלמידים?

🔧 הפתרון — שלב 1: הגדרה והשמה

int numSubjects = int.Parse(Console.ReadLine()); int numStudents = 3; Random rand = new Random(); // הגדרת המערך הדו-מימדי int[,] grades = new int[numStudents, numSubjects]; // מילוי בציונים אקראיים for (int i = 0; i < numStudents; i++) { for (int j = 0; j < numSubjects; j++) { grades[i, j] = rand.Next(0, 101); } }
📌 i = אינדקס התלמיד (שורה)  |  j = אינדקס המקצוע (עמודה)

🔧 הפתרון — שלב 2: ממוצע לכל תלמיד

// חישוב והדפסת ממוצע לכל תלמיד for (int i = 0; i < numStudents; i++) { int sum = 0; for (int j = 0; j < numSubjects; j++) { sum = sum + grades[i, j]; } double avg = (double)sum / numSubjects; Console.WriteLine("Student " + i + ": average = " + avg); }
📌 הלולאה החיצונית עוברת על תלמידים (שורות)
הלולאה הפנימית מסכמת את כל ציוני אותו תלמיד

🔧 הפתרון — שלב 3: ממוצע לכל מקצוע

// חישוב והדפסת ממוצע לכל מקצוע for (int i = 0; i < numSubjects; i++) { int sum = 0; for (int j = 0; j < numStudents; j++) { sum = sum + grades[j, i]; } double avg = (double)sum / numStudents; Console.WriteLine("Subject " + i + ": average = " + avg); }
📌 הלולאה החיצונית עוברת על מקצועות (עמודות)
הלולאה הפנימית מסכמת את ציוני כל התלמידים באותו מקצוע

📘 הגדרת מערך דו-מימדי

int[,] grades = new int[numStudents, numSubjects];
המספר הראשון = מספר השורות (תלמידים)
המספר השני = מספר העמודות (מקצועות)
כל התאים מאותחלים אוטומטית ל־0
עמודה 0עמודה 1עמודה 2
שורה 0000
שורה 1000
שורה 2000

📘 כתיבה לתא במערך

// כתיבה לתא בודד grades[1, 2] = 95; // כתיבה בלולאה מקוננת for (int i = 0; i < numStudents; i++) { for (int j = 0; j < numSubjects; j++) { grades[i, j] = rand.Next(0, 101); } }
📌 גישה לתא: grades[שורה, עמודה]
הלולאה החיצונית על שורות (i), הפנימית על עמודות (j)

📘 קריאה מתא במערך

// קריאה מתא בודד int g = grades[0, 1]; Console.WriteLine(grades[0, 1]); // קריאה בלולאה — סכימה לפי מקצוע for (int j = 0; j < numSubjects; j++) { int sum = 0; for (int i = 0; i < numStudents; i++) { sum = sum + grades[i, j]; } double avg = (double)sum / numStudents; Console.WriteLine("Subject " + j + ": average = " + avg); }

📘 אתחול עם ערכים ידועים מראש

כאשר הערכים ידועים מראש, ניתן לאתחל ישירות:

int[,] grades = new int[,] { { 85, 90, 78 }, // תלמיד 0 { 72, 68, 95 }, // תלמיד 1 { 88, 74, 82 } // תלמיד 2 };
כל סוגריים מסולסלים פנימיים = שורה אחת
הערכים בתוכם = ערכי העמודות של אותה שורה

🧠 אתגרים

השתמשו במערך grades שיצרתם — 3 תלמידים, numSubjects מקצועות, ציונים אקראיים.
  1. מצאו את הציון המקסימלי לכל תלמיד
  2. מצאו את הציון המקסימלי לכל מקצוע
  3. מצאו את הציון המקסימלי הכולל במערך
  4. ספרו כמה ציונים הם מעל 80
  5. מצאו את התלמיד עם הממוצע הגבוה ביותר

📝 סיכום

הגדרה לפי גודל:
int[,] arr = new int[rows, cols];
הגדרה עם ערכים:
int[,] arr = new int[,] {{1,2},{3,4}};
כתיבה וקריאה:
arr[i, j] = val;   x = arr[i, j];
גדלים:
arr.GetLength(0) / arr.GetLength(1)
🔁 מעבר על כל המערך = לולאה בתוך לולאה
לולאה חיצונית על שורות (i) ← לולאה פנימית על עמודות (j)
